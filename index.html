Sellco dashboard — data, APIs & queries

Generated from app-web routes + app-backend controllers and SQL under src/api/**/queries.

How to read “Amazon query” here. The browser calls Sellco REST APIs. Those handlers run BigQuery SQL (files like metrics-new.sql), not the Amazon Advertising API directly at request time. Rows come from datasets that Sellco fills from Amazon Ads reports, Amazon Marketing Stream (dataset often amazon_marketing_stream), and Selling Partner-style vendor/seller feeds (dataset sellcoai.sellco_amazon_sellor_vendor). Postgres is used for accounts, subscriptions, ASIN catalogue rows, AMC metadata, etc.
